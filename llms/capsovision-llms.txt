# CapsoVision

> CapsoVision, Inc. (Nasdaq: CV) is a commercial-stage medical technology company in
> Saratoga, California building capsule-endoscopy imaging and AI for gastrointestinal
> disease detection. Its CapsoCam Plus single-use capsule captures a 360-degree
> panoramic view of the small-bowel mucosa with no external receiver equipment, paired
> with the CapsoCloud cloud application and CapsoView review software.

CapsoVision publishes **no public API, no developer portal, and no machine-readable
specification**. CapsoCloud is an account-gated clinical web and mobile application;
its JSON backend under `www.capsocloud.com/api/` is private to the product and is not
documented for third parties. This file is generated by API Evangelist from public
sources — it is not a CapsoVision publication.

## Products

- [CapsoCam Plus](https://capsovision.com/): single-use 360-degree small-bowel capsule endoscope
- [CapsoCloud](https://www.capsocloud.com/): account-gated cloud application for image review, reporting and ordering
- [CapsoCloud FAQ](https://capsovision.com/capsocloud-faq/): customer-facing questions about the cloud application
- [Instructions for Use](https://capsovision.com/instructions-for-use/): product IFU documentation (clinical, not developer)
